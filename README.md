# apertureshift.com — Roads to the Future

Three free games that teach multidimensional thinking and the Singular language:

- `nine-numbers.html` — walk a nine-number phext address, one dimension at a time
- `word-home.html` — where words live in Will Bickford's Singular atlas
- `zap-zoom-echo.html` — rebuild a simple-word song, tile by tile

All games: free forever, same-screen multiplayer, no sign-up, no ads, no tracking.
Open `index.html` in a browser. MIT licensed — see `LICENSE`.
